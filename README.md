# 🏃 Sprint Time Predictor

A machine learning model that predicts 100m sprint times based on 
athlete statistics including training, sleep, strength, and reaction time.

## Built With
- Python
- Scikit-learn (Random Forest Regressor)
- Pandas

## Model Performance
- Mean Absolute Error: 0.12 seconds

## Features Used
Age, height, weight, sleep, hydration, training sessions, 
recovery days, squat, deadlift, reaction time, personal best
